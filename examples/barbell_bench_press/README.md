# Barbell Bench Press

Requires Blender 4.3.2, Python 3, NumPy and Pillow. The shared human is generated once at repository root with `blender -b --python rebuild_human.py`; it is read from `../../assets/improved_human.blend`. Asset license: [root asset license](../../assets/LICENSE.ASSETS.md). Run commands below from this example directory. Generated scenes, frames, and checks remain under `output/` and `qa/`.

```sh
blender -b -t 2 --python build_scene.py
blender -b -t 2 --python scripts/render.py
blender -b -t 2 --python scripts/validate_all.py
python package.py
```

The original build includes the red/blue muscle colors. No separate recoloring stage is needed. Motion records are generated by the builder and are required by rendering and validation.
